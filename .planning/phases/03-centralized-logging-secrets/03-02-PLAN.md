## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-06 | Information Disclosure | Insecure default secrets deployed to a real environment undetected | mitigate | `_check_default_secrets()` runs on every `create_app()` call and warns loudly (console + logger) the moment any in-scope secret matches a known-insecure default — catches the misconfiguration during the very first log review rather than staying silent indefinitely. |
| T-03-07 | Information Disclosure | .env.example accidentally committed with a real secret value copy-pasted from a real .env during authoring | mitigate | Task 2's acceptance criteria explicitly forbid any real-looking secret value; every secret line is either commented out or an obvious `CHANGE_ME` placeholder, never a working default. |
| T-03-08 | Denial of Service | A bug in `_check_default_secrets()` itself crashes `create_app()` at import time | mitigate | Function only reads `app.config`/`os.environ` and performs string comparisons — no I/O, no exceptions raised, no `exit()`/`sys.exit()` calls (explicit acceptance criterion), so it cannot itself take the service down even by accident. |

Severity note: No HIGH-severity item is deliberately left unmitigated in this plan; T-03-06 (the primary concern) is directly addressed by Task 1.
