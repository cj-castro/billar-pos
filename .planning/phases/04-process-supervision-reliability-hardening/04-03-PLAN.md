<objective>
Build the two PowerShell deliverables Phase 4's "is the POS up" gate depends on: a unified health-check rollup script (D-03, SUP-04) and a native-Postgres crash-restart policy closing the one supervision gap Phase 2 left open (Postgres has no `AppExit Default Restart` equivalent, unlike the 5 NSSM-wrapped services).

Output: `scripts/check-health.ps1` (standalone, operator-runnable); `scripts/configure-postgres-failure-recovery.ps1` (standalone + wired into `install-postgres-native.ps1`'s own install flow).
</objective>
