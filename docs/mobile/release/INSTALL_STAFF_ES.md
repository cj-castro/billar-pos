# Instalar Bola 8 Staff (Android)

Versión 1.1.0. Solo para el personal del club.

## Instalación
1. Recibe el archivo `bola8-staff-1.1.0-2.apk` (WhatsApp o enlace de Drive) y descárgalo.
2. Abre el archivo desde las notificaciones o desde la app **Archivos / Descargas**.
3. Si el teléfono lo pide, toca **Configuración** y activa **Permitir desde esta fuente**
   (o "Instalar apps desconocidas") para el navegador, WhatsApp o el gestor de archivos que usaste.
4. Regresa y toca **Instalar**. Si aparece un aviso de Play Protect, toca **Instalar de todos modos**.
5. Toca **Abrir**.

## Primer inicio
1. Conecta el teléfono al Wi-Fi **IZZI-428F-5G**.
2. Abre la app. Mostrará "Buscando servidor…" y lo encontrará sola.
3. Si no lo encuentra, escribe la dirección manualmente: `http://192.168.1.24:8080`
4. Inicia sesión con el usuario y la contraseña que te dé el encargado.

## Actualizar a una versión nueva
1. Descarga el APK nuevo igual que la primera vez.
2. Ábrelo e instala **encima** de la app actual. Es la misma firma.
3. **No desinstales** la app antes; tus datos y la configuración se conservan.

## Problemas comunes
- No encuentra el servidor: revisa que estés en el Wi-Fi **IZZI-428F-5G** y escribe la dirección del paso 3.
- "App no instalada": no mezcles APK de otra fuente. Pide el archivo oficial al encargado.
